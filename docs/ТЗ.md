# ТЗ: Thandor: Вторжение (рабочее название)
### Мобильная RTS для Android · прототип уровня 1 · версия 0.1

> Документ фиксирует договорённости по геймдизайну. Всё, что здесь описано, считается
> согласованным; спорные и отложенные пункты вынесены в разделы 13–14.
> Все числа баланса — стартовые, правятся в одном файле конфига (`prototype/js/config.js` в веб-прототипе,
> `res://core/config.gd` в Godot).

---

## 1. Концепция

| | |
|---|---|
| **Жанр** | RTS в реальном времени, одна карта = один бой |
| **Платформа** | Android (позже iOS), один палец, одна рука |
| **Ориентация** | **Только портрет**, вертикально |
| **Сеттинг** | Sci-fi в духе Thandor: Альянс Аварес против Голратов на планете Тандор |
| **Сессия уровня** | 6–10 минут |
| **Целевая аудитория** | Игроки 16–40, знакомые с RTS по ПК, играют в транспорте короткими сессиями |

**Одна фраза:** «Построй базу, выкачай ксенит, выбери ветку технологий и сотри
командный центр Голратов с карты — одной рукой, за семь минут».

## 2. Название и IP-риск ⚠️

Название: **THAN-DOR** (рабочее, согласовано 10.11; отдельно от IP оригинала).

Проверка показала: *Thandor: The Invasion* — реальная RTS 2000–2001 годов
(разработчики Planet 4 / Innonics, издатель JoWooD; в России издавалась Buka как
«Вторжение: Выжженная земля»). Товарный знак Thandor не зарегистрирован, издателя
больше нет, но **права на саму игру принадлежат Томасу Гереке и ещё трём лицам**.

**Решение:** используем **THAN-DOR** — иное написание, визуально и на слух близкое к
оригиналу, но не совпадающее с торговым знаком. Все ассеты, тексты и код — собственные,
копирование материалов игры не допускается: заимствуем **визуальный язык и дух механик**,
а не содержимое.

Название вынесено в конфиг: `TITLE = "THAN-DOR"`, подзаголовок `«Вторжение»`.

## 3. Технология

| Решение | Обоснование |
|---|---|
| **Движок: Godot 4.3+ (GDScript)** | MIT, бесплатно, официальный экспорт в Android, настоящий 2D (пиксельные координаты), лёгкий под 2D-RTS, ~15–25 МБ APK |
| **Почему не OpenRA** | Это порт C&C/Red Alert, а не движок для встраивания своей игры, и C#/SDL на мобиле тяжёл |
| **Почему не Unity** | Лишний вес и лицензионные сложности ради 2D-проекта такого масштаба |
| **Референс архитектуры** | `lampe-games/godot-open-rts` (MIT) — туман войны, миникарта, движение отрядов «роем»; берём идеи, не код |
| **Минимальная версия** | Android 8.0 (API 26), arm64-v8a + armeabi-v7a |
| **Производительность** | 60 FPS на устройстве уровня Redmi Note 10; логика 20 Гц, рендер интерполируется |
| **Размер APK** | цель ≤ 60 МБ (арт + 60–80 коротких озвучек) |

**Двухступенчатый процесс:**
1. **Веб-прототип** (HTML5 Canvas + JS, без фреймворков) — проверяем ощущения, вид, управление в «корпусе телефона». Запускается сразу, без сборки.
2. **Проект Godot 4** — перенос подтверждённых механик в целевую технологию, оттуда собирается APK.

Логика в веб-прототипе отделена от рендера (`js/sim.js` — чистая симуляция без DOM),
чтобы её можно было покрыть тестами и построчно перенести в GDScript.

## 4. Игровой цикл

```
Старт → 2 сборщика на ксените → ресурсы капают → Фабрика → войска
   ↓                                                    ↓
Техдерево (армия / экономика) ← ксенит ← экспансия на дальние залежи
   ↓                                                    ↓
      Армия растёт → волны Голратов → штурм базы врага → ПОБЕДА
```

Петля короткая и читаемая: **добыл → построил → выбрал технологию → нажал «Атака»**.

## 5. Экономика

- **Один ресурс в прототипе — ксенит** (золотистые кристаллы). В оригинале было два: ксенит (материал) и
  тритий (энергия). Второй ресурс — задел на уровень 2, в прототип не входит (см. `docs/Анализ_Thandor.md`).
- Стартовый капитал игрока: **350 ксенита**; врага: **420** (компенсация слабого ИИ).
- Залежь = группа тайлов; запас одной залежи **900 ксенита**, бур берёт **8 за раз**.
- Цикл бура: едет к ближайшей залежи → набирает 8 → везёт в Центр или Фабрику → сгружает → обратно.
- Сборщик окупается за ~4 рейса; охота на чужих сборщиков — легальная тактика (они беззащитны).
- Потолок армии: **30 единиц** (иначе телефон и баланс страдают).

## 7. Техдерево: две ветки

Исследуется в **Командном центре**, ресурс — кристаллы, время идёт параллельно постройке войск.
Игрок физически не может прокачать всё за один уровень: суммарная стоимость обеих ветвей
(~1680) больше добычи за бой (~1100) → **осмысленный выбор**.

### Ветка «АРМИЯ» (красная)

| # | Технология | Стоимость | Время | Эффект |
|---|---|---|---|---|
| А1 | Улучшенные орудия | 150 | 15 с | **открывает Артиллерию**, +10% урон |
| А2 | Плазма I | 180 | 18 с | +15% урон всем войскам |
| А3 | Композитная броня | 160 | 16 с | +25% HP техники (Штурмовик, Перехватчик) |
| А4 | Ионный двигатель | 220 | 22 с | **открывает Перехватчика**, +10% скорость |
| А5 | Плазма II | 260 | 26 с | ещё +25% урон |

### Ветка «ЭКОНОМИКА» (зелёная)

| # | Технология | Стоимость | Время | Эффект |
|---|---|---|---|---|
| Э1 | Экстракторы I | 140 | 14 с | +25% добыча бура |

## 8. Управление: полуавтоматический бой

Ключевое решение: **игрок не микроконтролит каждый выстрел**. Это RTS для одной руки.

| Жест | Действие |
|---|---|
| Тап по карте | выбор юнита/здания, показ карточки |
| Тап по пустому месту (юнит выбран) | приказ идти в точку |
| Перетаскивание по карте | прокрутка камеры (инерция) |
| Щипок двумя пальцами | зум 0.6×–1.4× |
| Двойной тап по юниту | выбрать всех юнитов этого типа |
| Кнопка **«ВСЕ ВОЙСКА»** | выделить всю армию |
| Кнопка **«АТАКА»** → тап по направлению | армия выдвигается, дальше воюет сама |
| Долгий тап по зданию | карточка: «Улучшить / Продать» |

**Автобой:** юнит сам выбирает ближайшую цель в радиусе обзора, сам подходит на дистанцию
стрельбы, сам отступает, если HP < 20% и рядом своя база. Игрок задаёт только
**направление и группу**. Это резко снижает цену ошибки на тач-экране.

**Обратная связь обязательна:** подсветка выделения, пунктирная линия приказа,
красные индикаторы HP, всплывающие «-9» над целью, лёгкий haptic-отклик на приказ.

## 9. Экран (портрет, 390 × 844 CSS px ≈ 1080 × 2340)

```
┌──────────────────────────────┐
│ 💎350  ▮▮▮ 0/30   ⏸    ⚙     │ ← статус-бар 52 px, в стиле панели
├──────────────────────────────┤
│                              │
│                              │
│         КАРТА (камера        │ ← игровое поле, ~52% высоты
│         сверху, объекты      │   миникарта — свёрнутый
│         с объёмом)           │   металлический бейдж
│                              │   справа сверху
│                    ◱ миникар.│
├──────────────────────────────┤
│ ┌──────┐ КОМАНДНЫЙ ЦЕНТР     │ ← карточка выбранного, 92 px
│ │превью│ HP ████████░ 1400   │   слева плоский силуэт-«чертёж»
│ │силуэт│ [УЛУЧШИТЬ] [ТЕХ]    │   справа имя, полоса, действия
│ └──────┘                     │
├──────────────────────────────┤
│ [СТРОЙКА]  [ТЕХ]  [АРМИЯ]    │ ← вкладки 40 px, активная подчёркнута
│ ┌────┐┌────┐┌────┐           │
│ │Стр.││Мол.││Стр.│           │ ← сетка 3×2, плитка 92×92 px
│ │80  ││140 ││110 │           │   стальная плитка с фаской,
│ └────┘└────┘└────┘           │   иконка + цена снизу
│ ┌────┐┌────┐┌────┐           │
│ │Зав.││Рад.││Гроза│          │
│ └────┘└────┘└────┘           │
├──────────────────────────────┤
│   [ ВСЕ ВОЙСКА ]  [ АТАКА ]  │ ← 56 px, главные действия
└──────────────────────────────┘
```

**Что взято из консоли оригинала:**
- **превью выбранного объекта** — но плоским «чертежом», а не 3D-рендером (сохраняем смысл, убираем стоимость);
- **плотная сетка плиток** одинакового размера — быстрый скан;
- **металлические панели** с фаской, врезками и уголками;
- **янтарные/зелёные индикаторы** и логотип-бейдж игры в углу панели.

**Что изменено под телефон:**
- консоль переехала из правого края вниз — под большой палец;
- плитки 92×92 px вместо ~24 px (требование Android ≥ 44 dp);
- вместо двух вкладок «стройка / построенное» — **одна вкладка со статусом**
  (доступно / не хватает ресурсов / закрыто технологией).

Принципы: всё управление в нижней трети; ни одного элемента меньше 44 dp; карта никогда
не перекрывается панелью (поле режется, а не наезжает); тёмный интерфейс — играем вечером.

## 10. Визуальный стиль: индустриальный флэт

Стиль выведен из оригинала (см. `docs/Анализ_Thandor.md`): Thandor был **земляным,
металлическим и приглушённым**, а не неоновым. Мы сохраняем его визуальный язык,
но переводим в плоскую технику, дешёвую в производстве и читаемую на 6 дюймах.

### 10.1 Камера — гибрид

- **Планировка сверху**: мир, сетка, залежи, препятствия, перемещение — всё в проекции сверху.
- **Объём у объектов**: здания и техника рисуются с лёгким «наклоном» — видна передняя
  грань и короткая тень, как в 3/4. Игрок читает объём, но координация не страдает.
- **Правило:** наклон только у силуэтов объектов, **никогда** у карты и приказов.

### 10.2 Палитра (снята со скриншотов оригинала)

| Роль | Цвет | Комментарий |
|---|---|---|
| Земля / грунт | `#6b7a3f` → `#8a8a52` | оливково-пыльная, сухая трава |
| Грязь / камень | `#5d5348`, `#7a5f42` | бурые, приглушённые |
| Песок | `#b8a179` | песчаные участки |
| Вода | `#2e5a6b` | тёмная бирюза |
| Растительность | `#3d5233` | тёмная зелень |
| Игрок (Альянс) | `#4a6b8a` | сине-серый выгоревший металл |
| Враг (Голраты) | `#8a3f34` | ржаво-красный |
| Кристаллы (ксенит) | `#d8a83a` → `#f0d27a` | золотистый, как в оригинале |
| Тритий (задел) | `#5fc8d8` | голубоватое свечение, в прототип не входит |
| Металл UI | `#3a3f45`, фаска `#6a7078`, врезка `#1d2126` | панели консоли |
| Индикатор хороший | `#7ddc3c` | зелёные полоски ресурсов |
| Индикатор в процессе | `#e8c020` | янтарные полоски |
| Огонь / взрыв | `#ff8a1e` → `#ffd35a` + чёрный дым | **главное акцентное пятно игры** |
| HP | `#6fdc4a` | зелёный, полоса 4 px |
| Текст | `#d9d3c4` | тёплый светло-серый, не белый |

Никакого неона и градиентного свечения — только огонь и индикаторы светятся.

### 10.3 Силуэты

- **Здания:** приземистые, промышленные — панели, трубы, антенны, купола, бетонное
  основание, вентиляция. Плоская заливка + передняя грань темнее на 12% + обводка 2 px
  цветом команды + короткая тень вправо-вниз.
- **Техника:** утилитарная — гусеницы/колёса, коробчатый корпус, башня с явным стволом.
  Глиссер — на «подушке» без колёс.
- **Пехота:** 3–4 точки-фигурки в отделении, читаются как отряд, а не как один солдат.
- **Кристаллы (ксенит):** золотистые гранёные кристаллы, растущие из земли.
- **Препятствия:** обломки скал, бетонные блоки, ржавые конструкции.

### 10.4 Интерфейс

- Плоские стальные панели: заливка `#3a3f45`, двойная обводка (`#6a7078` снаружи,
  `#1d2126` внутри), уголки-«скобки» по краям панели.
- Плитки кнопок: фаска сверху-слева светлее, снизу-справа темнее — эффект металла
  без рендера. Нажатие — вдавливание (сдвиг на 1 px, смена фаски).
- Шрифт: технический, без засечек, чуть разреженный, заглавные в подписях
  (в вебе — `Rajdhani`/`Barlow Condensed` с фолбэком на системный).
- Логотип **THAN-DOR** — бейдж в правом нижнем углу панели, как в оригинале.
- Миллиметровая сетка 8 px на панелях как текстура «чертежа».

### 10.5 Анимация и эффекты

Дешёвые, но характерные:
- взрыв: круг оранжевый → жёлтый + 5–7 чёрных клубов дыма, 0.5 с (крупный, как в оригинале);
- трассер: короткая жёлтая линия с затуханием;
- выстрел: вспышка у ствола, отдача корпуса на 1–2 px;
- постройка: каркас → рост заливки снизу вверх + янтарная полоска прогресса;
- выделение: зелёные уголки-скобки по углам габарита (как в оригинале).

### 10.6 Производство

Арт не требует художника на старте: всё рисуется примитивами Canvas/Godot-нодами
по единому описанию силуэта (polygon points в конфиге). Когда появится арт-пасс,
каждый юнит заменяется спрайтом без изменения логики — отрисовка изолирована в одном слое.

## 11. Звук и голос

**Анонсер: мужской, командирский, спокойный и низкий.** Короткие фразы, без пафоса.
**Юниты: мужские короткие реплики** на приказ и на события.

Требования: русский язык, 48 kHz mono, сжатие OGG, длина реплики **≤ 1.2 с**,
громкость нормализована, всего ~60–80 файлов → ~4–6 МБ.

### Скрипт анонсера (12 реплик)

| Событие | Фраза |
|---|---|
| База под ударом | «База атакована» |
| Не хватает ресурсов | «Недостаточно ресурсов» |
| Постройка готова | «Строительство завершено» |
| Юнит готов | «Подразделение готово» |
| Технология | «Технология исследована» |
| Приближается волна | «Обнаружено движение противника» |
| Враг замечен | «Контакт с противником» |
| Потерян юнит | «Мы потеряли подразделение» |
| Вражеская база повреждена | «Цель повреждена» |

## 12. Уровень 1: «Плацдарм Гелиос»

- **Карта:** 40 × 40 тайлов, база Альянса в левом нижнем углу, Голраты — в правом верхнем.
- **Цель:** уничтожить Командный центр Голратов.
- **Поражение:** потерян свой Командный центр.
- **Старт:** Центр + Фабрика + 2 бура + 1 пехота, 350 кристаллов.
- **Залежи:** 4 ближние (по 900), 3 спорные в центре (по 900) — за них начинается борьба.

**Тайминги:**

| Время | Событие |
|---|---|
| 0:00 | высадка, анонсер |
| 0:30 | подсказка «Постройте сборщик» |
| 0:55 | **волна 1**: 3 пехоты |
| 1:40 | **волна 2**: 4 пехоты + 1 штурмовик |
| 2:30 | **волна 3**: 5 + 2 штурмовика |
| далее | волна каждые 42 с, +1 юнит |
| — | ИИ защищает базу 2 турелями |

**ИИ:** экономика (до 3 сборщиков) → армия до 10 → атака по таймеру; защищает базу,
если она под ударом; не читерствует с ресурсами.

**Обучение:** не отдельный туториал, а 3 всплывающие подсказки в первые 40 секунд
(«Тап по ксениту», «Постройте Фабрику», «Кнопка АТАКА»).

**Награда за прохождение:** 1–3 звезды по времени и потерям (для будущей мета-прокачки).
