# THAN-DOR — мобильная RTS прототип

Мобильная RTS в духе *Thandor: The Invasion* (2000): одна карта, экономика на ксените,
две ветки технологий, полуавтоматический бой. Портрет, одна рука.

**Статус:** играбельный прототип одного уровня + основа проекта Godot для APK.

---

## Что где лежит

| Папка | Что это |
|---|---|
| **`docs/ТЗ.md`** | техническое задание: механики, ростер, техдерево, UI, звук, тайминги, риски |
| **`docs/Анализ_Thandor.md`** | разбор оригинальной игры: палитра, камера, консоль, что было сломано |
| **`docs/screens/`** | отрендеренные экраны прототипа (PNG 390×844) |
| **`prototype/`** | играбельный веб-прототип: HTML5 Canvas + JS, без зависимостей |
| **`godot/`** | проект Godot 4.3: экспорт в APK, та же логика на GDScript |
| **`tools/render-screens.js`** | рендер экранов в PNG для превью и проверки вёрстки |

---

## Запустить прототип

```bash
cd prototype
python3 -m http.server 8080
# открыть http://localhost:8080
```

Открывать именно через сервер, а не файлом: иначе браузер заблокирует загрузку озвучки.

**Управление:** тап — выбор, тап по земле — приказ, тап по ксениту сборщиком — добыча,
перетаскивание — камера, щипок — зум, `R` — заново, `Пробел` — вся армия, `M` — звук.

---

## Проверить логику

```bash
node prototype/test/sim.test.js
```

Симуляция не зависит от DOM, поэтому тестируется в Node: экономика, производство,
технологии, бой, туман войны, пути, победа/поражение, ИИ.

---

## Собрать APK

См. `godot/README.md`. Коротко: Godot 4.3 → Import `godot/project.godot` → установить
Android Build Template → Project → Export → Android (arm64-v8a) → `build/thandor.apk`.

## Важно про название

*Thandor: The Invasion* — игра 2000 года (Planet 4 / Innonics, издатель JoWooD).
Товарный знак не зарегистрирован, но права на игру принадлежат частным лицам.
Название **THAN-DOR** выбрано как иное написание; все ассеты, код и тексты — собственные,
заимствуется только визуальный язык и дух механик. Перед публикацией — проверка на ТМ.
